História da Web

Primeiros computadores

Na primeira geração de computadores que começou no ano de 1944 Com o Harvard Mark I. Era um eletromecânico, ou seja era muito grande e servia para realizar diversos cálculos. O grande problema é que esquentava muito.

Esses computadores ocupavam grande parte da sala. Em 1946 surgiu o Colossus, seu objetivo era para cripto análises. Com esse computador em especifico usado pela Alemanha na Segunda Guerra mundial, foi utilizado para

cálculos da guerra.

Termo Bug

Nessa época que foi criado o termo bug(inseto). Esses insetos pousavam nesses equipamento que por sua vez acabavam danificando, então pessoas tinham que ir manualmente arrumar esses computadores.

Segunda geração (1959 a 1965)

Nessa segunda geração dos computadores eles alteram das valvulas mecanicas para transistores, reduzindo drasticamente o tamanho, o que já causa uma evolução enorme para aquela época.

Terceira Geração (1965 a 1970)

Na terceira Geração dos computadores chegaram os circuitos integrados, que seriam os chips. Reduzindo cada vez mais os tamanhos dos computadores e também uma maior facilidade para transportar ele de um lugar para outro.

Quarta geração (a partir de 1971)

A quarta geração dos computadores são marcadas pelo mouse que foi adicionado e com o passar do tempo evoluindo cada vez mais, seriam hoje os computadores com RGB e peças cada vez menores, porém muito mais eficiente.

Ficando cada vez mais fácil e simples de transportar os computadores para cada canto e até local distante.

Surgimento - WEB

Internet - comunicação

Arpa net - sistema de comunicação baseado em pacotes que permitia passar por múltiplos pontos salvando como checkpoints, que basicamente seria hoje em dia os roteadores de internet. São os "Avô dos roteadores".

  • Primeira queda : 29/10/1969
  • Enviaram a palavra login, porém só chegou "LO", ou seja primeira palavra transmitida

Considerado pai da internet, unindo as ideias do TCP/IP e criou o WORLD WIDE WEB(WWW), sendo o primeiro navegador, utilizando a marcação de texto HTML. Primeira página da Internet

Clients X server

Clients

Clients é aquele dispositivo que está pegando/consumindo alguma informação da internet. Se Comunicam na internet atráves de outro computador(servidor).

Quando está trabalhando no lado dos clients tem que se preocupar por onde o seu usuário vai utilizar o seu site. Hoje cada vez mais dispositivos estão entrando na internet.

Por isso é bom ter a responsividade em dia, para que cada dispositivo que entre funcione perfeitamente sem quebrar o Layout da aplicação web e que passe uma ótima experiência para o usuário.

Aplicação-web

São os sites que você acessa pelos navegadores. Por exemplo, se você usar o site do Youtube é uma aplicação web, porém se abrir o aplicativo instalado, já não é mais uma aplicação web.

Server

Servidor

É um computador (ou sistema) que fornece serviços para outros computadores. Exemplo: quando você acessa um site, um servidor envia esse site pra você.

Nesse meio existe também os tipos de servidores

  • Servidor de arquivo

    • Você pode armazenar arquivos nesse servidor.

  • Servidor de E-mail

    • Nesse servidor é especificamente para armazenar e-mail.

  • Servidor de Fotos

    • Nesse servidor você vai armazenar fotos.

  • Servidor de web

    • E nesse seria para servidores web - por exemplo NGIX

HTML na prática

O que é HTML?

HTML significa Linguagem de Marcação de Hipertexto. Ele é usado para estruturar páginas na web.

Principais tags

<h1> até <h6> → Títulos

<p> → Parágrafos

<a> → Links

<hr> → Linha horizontal

<br> → Quebra de linha

<small> → Texto menor

<span> → Texto genérico
